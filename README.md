## 🔨 Recent Work

### **[Facet: Gemma Finetuner](https://github.com/gemma-facet)**
  - End-to-end platform to preprocess datasets, fine-tune Gemma models, run inference, and export in multiple formats
  - Built during GSoC 2025 with Google DeepMind
  - FastAPI, Next.js, Hugging Face, GCP

### **[IncliArray](https://github.com/inclinedadarsh/incliarray)**
  - PyTorch-like minimal N-dimensional float array library in C++
  - Row-major layout, stride-aware indexing, broadcasting, matmul, reductions, and lightweight reverse-mode autograd
  - Think NumPy meets autograd, but in C++

### **[Inclinet](https://github.com/inclinedadarsh/inclinet)**
  - Neural network library from scratch in Python with PyTorch-like APIs
  - Multiple activation functions, losses, and optimizers built from first principles

### **[Anon Forum](https://github.com/inclinedadarsh/anon)**
  - Anonymous social platform for my college
  - College verification via Google OAuth with zero personal data storage
  - Optimistic UI, FastAPI backend, Next.js frontend, deployed on AWS
